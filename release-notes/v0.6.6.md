# Xtension v0.6.6

Security and store-readiness release. No feature change.

## Fixed

- **Dictation no longer opens the microphone for nothing.** The button now asks the connector whether transcription exists *before* requesting microphone access. With the ChatGPT-managed Codex account it reports unavailable with no permission prompt at all, instead of recording first and failing afterwards.
- **The local connector is no longer reachable by other local processes.** It now requires a browser-extension `Origin` and validates the `Host` header. This closes DNS rebinding and prevents any other program on the machine — including another Windows session on the same PC — from reading the connected ChatGPT account or spending its quota. A new `/ping` route exposes liveness only, with no account data, for install-time checks.
- **The page can no longer trigger AI actions.** Composer handlers ignore synthetic events and only trust buttons the extension actually created, so a script running inside x.com cannot fire correction or generation on the user's behalf.
- **Image fetches are restricted** to the public X/Twitter media hosts, and the Codex sign-in page is only opened when it is an OpenAI HTTPS address.
- **Installer hardening:** `sc.exe` and `schtasks.exe` run from their absolute `System32` paths, so a same-named binary earlier in `PATH` cannot be executed instead.

## Firefox

- Permanent add-on id `xtension@jodevelop.com` replaces the `example.invalid` placeholder.
- Adds the `data_collection_permissions` declaration AMO requires.

## Documentation

- `PRIVACY.md` documents the dictation preflight, the microphone case, the sanitized local diagnostic log, and the files the separately installed connector writes.
- Store listings and manifest descriptions describe the actual 0.6.x feature set instead of the 0.4 PDF-only wording.

## Downloads

Everything is attached to this release and mirrored behind stable URLs at **https://xtension.jodevelop.com**.

The browser packages are built by GitHub Actions from this tag, so their checksums are reproducible from the source. The Windows connector is built and signed on Windows with Microsoft Trusted Signing, and timestamped. It installs for the current user only, needs no administrator rights, and is optional: PDF export works without it.
