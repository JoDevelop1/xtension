# Xtension v0.6.27

This release adds a third X/Twitter relationship state directly to the timeline.

- **✕ Not following** remains red.
- **✓ Following** remains blue.
- **↔ Mutual** is yellow-gold when X explicitly reports that both accounts follow each other.

Xtension obtains both directions from the `following` and `followed_by` fields already present in X's GraphQL timeline responses. It does not open hover cards or send one request per profile. If the reverse relationship is absent, Xtension keeps the ordinary **Following** state instead of guessing that the relationship is mutual.
