# Xtension v0.6.8

Latency release. No feature change, no interface change.

## Measured result

Repeated draft corrections, alternating each request between the old and the new connector so that service-side variability affects both equally:

| | before | after |
|---|---|---|
| full result | 5823 ms | **3266 ms** (−44 %) |
| first word on screen | 5823 ms | **2817 ms** (−52 %) |

## What changed

- **No more reasoning summary.** Codex was asked for a summary of its own reasoning on every request. Xtension never displayed it, and producing it cost about 1.8 s. This was the single largest win.
- **Default reasoning effort `medium` instead of `max`.** On a tweet-length correction or translation the output is equivalent, for roughly 1.2 s less. Existing installs are migrated only if they still carry the old default — a value you chose yourself is preserved — and the setting stays available if you want more reasoning.
- **The OAuth token is no longer refreshed before every request.** The account is read once and cached for ten minutes, invalidated on sign-in, sign-out, or any authentication failure. About 0.4 s per request.
- **A Codex thread is prepared while you type**, so the request no longer waits for one to be created.
- **Correction and translation now stream**, as generation already did. The text appears as it is written instead of after a frozen wait.

Model choice was measured as well: on these short tasks `gpt-5.4-mini` and `gpt-5.3-codex-spark` are *slower* than `gpt-5.6-luna`, so the default model is unchanged.

The remaining ~3 s is inference time on OpenAI's side and cannot be reduced from the extension.

## Security

The connector's guards are unchanged and were re-verified on the final signed binary: a request without a browser-extension `Origin` is refused, the `Host` header is validated against DNS rebinding, `/ping` exposes liveness only, and there is still no audio-capture code anywhere in the packages.

## Downloads

Everything is attached to this release and mirrored at **https://xtension.jodevelop.com**. Browser packages are built by GitHub Actions from this tag; the Windows connector is built and signed on Windows with Microsoft Trusted Signing.

Update both the extension and the connector to get the full gain.
