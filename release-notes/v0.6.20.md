# Xtension v0.6.20

This maintenance release keeps Xtension's X/Twitter relationship badge and **Reply** button on the author line when a post uses a long verified display name.

Xtension now identifies the complete X author row before inserting its controls. The native display name or handle can shrink when space is tight, while **Following** / **Not following** and **Reply** remain together on the first line.

The fix was regression-tested against the `Gaëtan Caillot (Bambino)` layout reported from the home timeline and verified in an isolated real-browser rendering.
