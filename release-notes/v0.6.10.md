# Xtension v0.6.10

Transparency on where the download comes from.

The connector download link — in the extension's options page and on the website — now points **directly at `github.com`**:

```text
https://github.com/JoDevelop1/xtension/releases/latest/download/XtensionBridgeSetup.exe
```

Previously it pointed at `xtension.jodevelop.com/dl/XtensionBridgeSetup.exe`, which redirected to the very same GitHub asset. The file was always the same, and nothing was ever hosted anywhere else — but you only discovered the real source *after* clicking. Now you can see it beforehand, in the status bar of your browser, which is what matters for a binary you are about to run.

The browser packages and the checksum file on the website point at GitHub the same way, and the download section says so in plain words.

The `xtension.jodevelop.com/dl/…` aliases still resolve to the same assets: extensions installed before this version, and any script using them, keep working.
