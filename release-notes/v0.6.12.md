# Xtension v0.6.12

This release makes generated messages easier to read and reduces avoidable waiting in short writing tasks.

## Improved

- **Readable short paragraphs.** Generated posts and medium or long reply suggestions now separate distinct sentences or ideas with one blank line instead of returning a dense text block.
- **Blank lines survive insertion.** The extension no longer collapses intentional paragraph breaks while cleaning streamed model output before sending it to the X/Twitter editor.
- **Faster default reasoning.** Luna now uses low reasoning by default for these narrowly scoped writing operations. The choice remains available in Settings for users who prefer a higher effort.
- **Continuous thread prewarming.** Once a Codex turn starts, the connector prepares a fresh ephemeral thread for the next request.
- **No repeated image conversion.** Parallel suggestions share the same short-lived contextual image conversion instead of downloading and encoding the image three times.

Custom generation prompts and custom reply profiles are preserved. Only the previous built-in defaults are migrated to the new paragraph-aware defaults.

## Downloads

Download the browser package for your browser and, for AI features on Windows, `XtensionBridgeSetup.exe`. Verify downloads with the attached SHA-256 files.
