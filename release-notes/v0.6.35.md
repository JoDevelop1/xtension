# Xtension v0.6.35

Xtension can now use three no-API-key AI paths for text writing:

- OpenAI Codex through the existing ChatGPT account;
- Claude Code through an existing Claude subscription session;
- Ollama on localhost or a private-network server.

Options lets the user choose a preferred engine and model, configure Ollama's URL, and enable safe fallback. Fallback attempts providers one at a time and never changes engine after text output has started. Images remain on Codex because the Claude Code and Ollama integrations are text-only.

The Claude path disables tools, MCP, slash commands, session persistence, API-key environment variables, and automatic retries. The Ollama path disables thinking, requests constrained JSON, bounds context, and rejects public-server URLs. The consent and privacy disclosures have been updated for all supported locales.
