# Xtension v0.6.34

This release restores reliable AI draft insertion on X/Twitter.

- A draft is now considered inserted when the generated text is present in X's editor. A disabled **Post** button no longer turns a successful insertion into the misleading “X did not accept the insertion” error.
- New X/Twitter posts and replies are requested at no more than 280 visible characters so they remain usable on accounts without long-post access.
- Provider errors from the streaming path keep their original code and message.
- Quota, sign-in, timeout, overload, and connector failures are no longer replayed as a second hidden AI request.
- Native Windows `SendInput` targeting remains guarded, and Xtension still never submits or publishes a post automatically.
