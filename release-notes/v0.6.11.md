# Xtension v0.6.11

This release repairs the connector/update path and makes diagnostics practical to share.

## Fixed

- **Copy diagnostic logs in one click.** The logs panel now has a dedicated Copy button with clear success or failure feedback.
- **Select only the logs.** Logs are displayed in an isolated read-only text area, so dragging or pressing Ctrl+A no longer selects button labels such as Refresh, Clear, or Save settings.
- **Detect stale connectors.** The settings page displays the connector version and asks for an update when the installed executable is older than the extension. AI actions no longer run silently through an incompatible legacy connector.
- **Give ImageGen enough time.** Long image generations can now run for up to ten minutes instead of failing at exactly five. The connector also preserves the real Codex turn error and recovers a completed image from the final turn payload if needed.
- **Keep every version in sync.** Browser packages, connector metadata, the Windows installer, and the site now derive their version from the same release value. Windows Apps & Features shows the actual installed version.
- **Keep settings responsive.** Save, navigation, and log controls are wired before connectivity checks, and a status request cannot wait forever.

## Important connector update

Install the v0.6.11 `XtensionBridgeSetup.exe` even if the browser extension was already updated. Earlier connector installers could continue running an older executable without making that mismatch visible in Xtension.

## Downloads

Download the browser package for your browser and, for AI features on Windows, `XtensionBridgeSetup.exe`. Verify downloads with the attached SHA-256 files.
