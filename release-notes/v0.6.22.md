# Xtension v0.6.22

This layout release gives X/Twitter author information a clear two-line structure.

The display name, relationship badge, and green **Reply** button stay together on the first line. The native `@handle · time` metadata now occupies a dedicated second line beneath them, instead of extending the controls row horizontally.

The real-browser layout harness covers a long verified display name and verifies both requirements independently: the three first-line elements have identical vertical centers, and the metadata begins below all of them.
