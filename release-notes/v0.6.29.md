# Xtension v0.6.29

This corrective release keeps the Chrome Web Store privacy and security hardening from v0.6.28 while restoring the intended separation between local X/Twitter relationship badges and optional AI processing.

- Following, followed-by, and mutual badges work locally without AI consent, a connector, or a ChatGPT account.
- AI data consent remains required only for correction, translation, generation, contextual suggestions, and image generation.
- Options now state explicitly that consent does not sign the user into ChatGPT; connection is a separate step handled by the local connector and official OpenAI sign-in.
- X/Twitter PDF export remains fully local and unchanged.
