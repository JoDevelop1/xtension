# Xtension v0.6.31

This corrective release restores ChatGPT connectivity for existing Xtension installations and reorganizes Options around the actual setup order.

- Fixes the `Origin is not allowed` connector regression for the fixed legacy Xtension package ID while arbitrary extensions and websites remain blocked.
- Puts the important actions in order: enable AI, install or update the local connector, then connect the user's ChatGPT account.
- Saves the AI switch immediately and replaces the raw origin error with a clear localized recovery message.
- Moves model settings into a secondary collapsed section and gives the main status cards consistent alignment and spacing.
- Keeps PDF export, relationship badges, writing, image generation, prompts, and diagnostics unchanged.
