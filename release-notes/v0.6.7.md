# Xtension v0.6.7

## Voice dictation removed

ChatGPT-managed Codex exposes no transcription model, so dictation could never produce a result — it only opened the microphone and failed afterwards. Rather than ship a code path that never worked, it is gone: the button, the microphone capture, the recorder, the voice-activity detection, the phrase queue and the `/transcribe` route on the connector.

The browser packages now contain **zero** occurrences of `getUserMedia`, `MediaRecorder`, `AudioContext` or any audio-capture code. Nothing can request microphone access, and no audio declaration is needed on any store form. Speech input, if it ever comes back, will be a separate application.

This also trims about 50 KB from every package.

## Downloads

Everything is attached to this release and mirrored behind stable URLs at **https://xtension.jodevelop.com**.

The browser packages are built by GitHub Actions from this tag, so their checksums are reproducible from the source. Their published values are in `SHA256SUMS.txt` below. The Windows connector is built and signed on Windows with Microsoft Trusted Signing, and timestamped. It installs for the current user only, needs no administrator rights, and is optional: PDF export works without it.
