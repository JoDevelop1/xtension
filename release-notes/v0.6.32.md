# Xtension v0.6.32

This release makes the optional Windows connector explicit and self-maintaining.

- Options shows both the installed connector version and the latest published version.
- The action is now state-specific: **Install connector** when absent, **Update connector** when outdated, and an up-to-date confirmation when current.
- Connectors from this release onward check for updates automatically and install them silently only after verifying the published SHA-256, the NOVA2G Authenticode signature, and the signed installer's release version.
- The connector waits until no AI or native typing request is active, runs the signed installer, and restarts through its existing per-user supervisor without losing the user's ChatGPT sign-in.
- The 0.6.31 connector needs this one final manual installer run; later connector updates can complete automatically.
- PDF export, relationship badges, writing, translation, image generation, prompts, and diagnostics are unchanged.
