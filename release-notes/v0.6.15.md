# Xtension v0.6.15

This maintenance release fixes native text insertion in Edge tab groups and multi-selected tabs whose native window title remains unrelated to the active X/Twitter page.

- Xtension first captures the exact foreground browser window, process, UI thread, and focused native child control.
- The connector keeps that snapshot behind a cryptographically random, single-use token for at most five seconds.
- The native helper calls `SendInput` only if every captured Windows target value still matches.
- No page title change or title comparison is involved.

Native-input protocol 3 is required on both the extension and connector, preventing mixed older components from using the title-based flows.
