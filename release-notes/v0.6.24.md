# Xtension v0.6.24

This release restores the X/Twitter post time or date that could disappear after the v0.6.23 author-row layout change.

X places the native timestamp inside a nested metadata container that clips overflowing content. Xtension now keeps that timestamp as its synchronized source and mirrors its clickable link directly into the first author line, outside the clipped container. The time or date remains visible at the far right, while only the `@handle` stays on the second line, flush with the display name and without a leading gap.

A new regression fixture reproduces X's nested overflow structure and verifies both that the visible timestamp remains aligned on the first line and that the hidden native source does not create a duplicate.
