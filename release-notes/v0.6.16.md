# Xtension v0.6.16

Image generation now uses the first still image in the post as a visual reference by default.

- The option is checked automatically when the Image AI dialog opens.
- Xtension immediately downloads and displays the exact source-image thumbnail, so the selected reference can be verified before generation.
- Reply modals that omit the tweet image reuse the photo captured from the exact post whose Reply button was clicked.
- GIFs, videos, and video thumbnails are deliberately excluded.
- If the checked reference cannot be downloaded or validated, generation stops with a clear message instead of continuing silently without the image.
- Extension and connector diagnostics separately record whether the reference was requested and whether a valid image was received. Image bytes are never written to logs.
