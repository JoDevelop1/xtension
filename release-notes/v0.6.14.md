# Xtension v0.6.14

This maintenance release fixes native text insertion in Edge profiles that expose a grouped or workspace window title rather than the active page title.

- Xtension briefly gives the active tab a random one-request marker.
- The Windows helper requires the foreground browser window to contain that exact marker before calling `SendInput`.
- The original X/Twitter title is restored immediately.
- The browser process, foreground window, native focused child, and single-operation lock remain enforced.

Native-input protocol 2 is required on both the extension and connector, preventing mixed 0.6.13 components from silently using the fragile title comparison.
