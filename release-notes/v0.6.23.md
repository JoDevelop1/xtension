# Xtension v0.6.23

This release completes the X/Twitter author-row layout with three stable zones.

The display name, relationship badge, and green **Reply** button remain at the left of the first line. The native post time or date sits at the far right of that same line. Only the `@handle` appears on the second line, flush with the display name and without a leading gap. Native links and hover behavior remain intact.

It also fixes the recurring timeline cleanup that removed layout markers from tweets enhanced during an earlier pass. A dedicated regression test now verifies marker persistence, while the real-browser harness independently measures first-line alignment, right-edge timestamp placement, second-line handle placement, and metadata colors.
