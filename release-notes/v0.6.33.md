# Xtension v0.6.33

This is the final hardened release of the new connector version and automatic-update flow.

- Options shows the installed connector version and the latest published version.
- **Install connector** appears only when no connector is detected; **Update connector** appears only when a newer release exists; current installations show an up-to-date confirmation with no unnecessary action.
- Future connector updates download and install silently while idle only after the public SHA-256, NOVA2G Authenticode signature, and signed installer version all pass verification.
- Windows signature verification now imports the trusted system security module explicitly, independent of PowerShell environment customizations.
- Self-update mode stops the old host and bridge without terminating the signed installer that is replacing them, then the per-user supervisor starts the new connector.
- A public-release integration test observed the connector restart and confirmed that ChatGPT authentication remained connected.
- Connectors older than 0.6.33 need this one final manual installer run; subsequent connector updates can be automatic.
- PDF export, relationship badges, writing, translation, image generation, prompts, and diagnostics are unchanged.
