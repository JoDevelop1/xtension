# Xtension v0.6.28

This release prepares Xtension for its Chrome Web Store update without removing PDF export.

- AI processing is now disabled until the user accepts a clear privacy disclosure in Xtension options. The disclosure covers visible social content, drafts, public author identifiers, source URLs, media context, OpenAI processing, and contextual suggestions after deliberate focus in an empty reply field.
- X/Twitter PDF export remains entirely local and works without AI consent or the Windows connector.
- The local Codex Connector now accepts only Xtension's official Chrome Web Store origin by default. Explicitly configured development or alternate-browser origins also require a shared local secret.
- Store copy, the public privacy policy, permission justifications, data-type declarations, icon padding, and screenshots are aligned with the current extension behavior.
- Generated text and images remain under user control; Xtension never activates a final publish button.
