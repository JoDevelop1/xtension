# Xtension v0.6.18

Reply language now follows the post text currently displayed by X.

- Xtension uses the visible post's `lang` attribute when available and otherwise infers the language from the visible text.
- Translation banners and automatic **Show original** interactions were removed.
- Users choose a separate display language for translations in Xtension settings; French is the default.
- Suggested replies in another language include a translation underneath, while only the original reply is inserted into X.
- The reply dialog still targets the closest preceding post.
