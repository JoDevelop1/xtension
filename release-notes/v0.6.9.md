# Xtension v0.6.9

Fixes image generation.

## The bug

The connector allowed up to **5 minutes** for Codex to produce an image, but its HTTP server closed the connection after **4 minutes**. A long generation was therefore genuinely completed by Codex — and logged as `request_done` — while the browser never received the result. The image simply never appeared, with no error to explain why.

Image generation legitimately takes one to three minutes, so this was reachable in normal use. The connection now outlives the longest possible operation.

## Also

The image dialog counts the elapsed seconds while generating. A dialog frozen for two minutes was indistinguishable from a hang. Errors now report how long they took, which tells an immediate failure (connector stopped) apart from an abandoned long generation.
