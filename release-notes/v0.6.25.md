# Xtension v0.6.25

This release corrects the remaining X/Twitter timestamp alignment issue visible in v0.6.24.

On a primary timeline post, Xtension now inserts the exact timestamp supplied by X immediately before the native Grok and overflow-menu action group. It no longer stops at the earlier right edge of the author-name block, which left an unnatural empty gap before those icons. Xtension does not reformat the value: the native link and `<time>` content are cloned unchanged and resynchronized whenever X updates them.

Quoted posts and cards without the native action group retain the far-right author-row fallback. The `@handle` remains alone on the second line, flush with the display name.
