# Xtension v0.6.26

This release separates Xtension's draft-action controls from X/Twitter's native toolbar in top-level post composers.

In the **What's happening?** composer, Xtension now uses its own full-width row immediately above X's media and publish controls. Correction, translation, generation, suggestions, image generation, undo/redo, and language selection no longer cover the native image, GIF, poll, emoji, scheduling, location, or publish buttons.

The dedicated layout recognizes top-level post controls in the supported English, French, German, Spanish, and Japanese interfaces. Reply composers retain their existing dedicated Xtension row.
