# Xtension v0.6.17

Automatic reply language now follows the original post, even when X translates that post into the account's interface language.

- Xtension reads X's source-language banner and opens localized **Show original** controls before collecting the post text.
- In reply dialogs containing a conversation chain, Xtension now uses the closest preceding post instead of the first post in the dialog.
- Translation metadata in accessible labels is read as well as visible banner text, and an unrestored translated text is never treated as the source language.
- Auto no longer uses the account language as a fallback when a source post is present.
- The options page now warms up the connector and retries transient startup states automatically, so a working connection no longer stays red until **Test connection** is clicked.
- Reply suggestions preserve their blank lines through display and native insertion.
- Generated posts and replies use one short paragraph per distinct sentence or idea, with as many airy paragraphs as the content needs rather than an artificial two/three-paragraph target.
- Existing custom prompts remain unchanged; only the previous built-in defaults are migrated.
