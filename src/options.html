Optional AI features

When you use an AI feature, your selected text and useful on-screen context are sent by the local connector only to the engine selected for that attempt: OpenAI Codex, Claude Code, or your configured Ollama server. Automatic suggestions use the same context. JoDevelop does not receive or store this data. PDF export and relationship badges stay local.

This switch does not sign you in. Install the connector, then use an existing ChatGPT or Claude subscription, or a local Ollama model. No API key is requested. How data is used
